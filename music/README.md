# Biblioteca de audio

**Sube aquí las canciones de Sonory Lab.** La plataforma explora esta carpeta y todas sus subcarpetas de forma automática.

Formatos detectados: MP3, WAV, OGG, OGA, OPUS, M4A, AAC, FLAC, MP4 y WEBM.

Organización sugerida:

```text
music/
├── singles/
├── albums/
└── ambient/
```

No es necesario modificar `index.html` al añadir nuevas pistas.
